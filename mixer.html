Your first transition — a quick guide

1. Load a file on each deck, or try the demo grooves. Files stay on your device.
2. Tap the beat with TAP to set each track’s BPM, then use SYNC to match tempos. Sync aligns tempo only; use the jog buttons to align the beat.
3. Start A with the crossfader to the left. Start B, lower its bass, then slowly move the crossfader right while swapping the bass.
4. Set a cue or a loop at the playhead. Record captures the master mix, including EQ and effects.

Keyboard: Space = deck A play/pause · Shift+Space = deck B · ← / → = crossfader · R = record. Tempo changes pitch; key lock, stem separation, and headphone pre-cue routing aren’t included. Loop timing follows your manually set BPM.
